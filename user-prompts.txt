프롬프트 1
======================================================================
The current directory is for a C# WPF project. Here we want to develop a small always-on-top desktop widget for Windows 11. On the widget, there should be a filed where the user can enter a number (price), and next to it, there should be a dropdown box where the user can select currency (The default should be JPY, and it should remember the last selected currency). Once the user enters the price in the selected currency, the app should immediately display the amount converted to KRW, using the up-to-date currency rate (should be obtained via the Internet). And the app should also display the customs duty that the user should pay to buy the thing with that price through a foreign online shopping mall. Also the total amount of money (the price in KRW plus the customs duty) should be displayed. The widget should be movable using mouse drag-and-drop, but should not be resizable. The user should be able to close the widget if they don't want to see it for a while. We are developping it in WSL 2 environment (dotnet.exe is already installed and ready to use), but it should be executed in Windows 11 native environment. Now, generate a proper AGENTS.md and develop this app. Make small Git commits so that we can track the history.
