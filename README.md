# 얼마일까 (HowMuch)

Windows 11용 해외직구 원화·관부가세 예상 계산 위젯입니다. 화면, 도움말, 오류 안내는 한국어이며, 384 × 622 크기의 고정 창으로 항상 위에 표시됩니다.

## 사용 방법

1. `howmuch.exe`를 Windows에서 실행합니다.
2. 상품 가격과 통화를 입력합니다. 통화 목록은 **JPY → USD → EUR**로 시작하며, 처음에는 JPY를 선택합니다. 이후에는 마지막 통화와 창 위치를 복원합니다. 지원하지 않는 통화가 저장되어 있으면 JPY로 대체합니다.
3. 실제 발송지가 미국이면 **미국에서 발송**을 선택합니다. USD 결제 여부와는 별개입니다.
4. **일반 물품(목록 통관 대상)** 또는 **식품, 건강기능식품 등 목록통관 제외 물품**을 선택합니다. 기본값은 일반 물품입니다.
5. 원화 가격, 예상 관세, 부가세, 총액이 즉시 갱신됩니다. 필요하면 **추가 설정**을 펼쳐 국제 배송비·보험료와 품목별 관세율을 입력합니다. 덜 자주 사용하는 화면 테마는 그 아래에 있습니다. 창 크기는 변하지 않으며 내용이 길면 스크롤할 수 있습니다.

상품 가격에는 현지 세금과 현지 배송비를 포함하세요. 국제 배송비·보험료는 같은 통화로 추가 설정에 별도 입력합니다. 소수점은 마침표를 사용하며 `12,345.67` 형식도 지원합니다.

제목 표시줄을 드래그하면 이동합니다. **−**는 작업 표시줄로 최소화, **×** 또는 Alt+F4는 종료입니다. 최소화한 창은 작업 표시줄에서 복원하고, 종료한 앱은 실행 파일로 다시 엽니다. 테두리 드래그나 제목 표시줄 더블클릭으로 크기를 바꿀 수 없습니다.

## 지원 통화

JPY(일본 엔), USD(미국 달러), EUR(유로)를 먼저 표시합니다. CNY(중국 위안), GBP(영국 파운드), AUD(호주 달러), CAD(캐나다 달러), CHF(스위스 프랑), HKD(홍콩 달러), SGD(싱가포르 달러), TWD(대만 달러), THB(태국 바트), NZD(뉴질랜드 달러), VND(베트남 동)도 지원합니다.

모든 통화에서 KRW 환율로 가격을 환산하고 USD 환율로 면세 기준을 판단합니다. 통화별 저장 환율을 독립적으로 관리합니다.

## 단축키

위젯 창에 포커스가 있을 때 사용할 수 있습니다. 제목 표시줄의 **?** 또는 **F1**으로 한국어 안내를 엽니다. 다른 앱에 포커스가 있거나 위젯이 최소화된 상태에는 적용되지 않습니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+L | 가격 입력으로 이동하고 전체 선택 |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | JPY / USD / EUR 선택 |
| Ctrl+U | 미국 발송 선택·해제 |
| Ctrl+G | 일반 물품 선택 |
| Ctrl+Shift+G | 목록통관 제외 물품 선택 |
| F5 | 환율 새로고침 (진행 중에는 추가 요청 차단) |
| Ctrl+T | 갸루·클래식 테마 전환 |
| Ctrl+, | 추가 설정 펼치기·접기 |
| Ctrl+M | 작업 표시줄로 최소화 |
| Ctrl+W / Alt+F4 | 위젯 종료 |
| F1 | 단축키 안내 열기·닫기 |
| Esc | 단축키 안내 닫기 |

Tab·Shift+Tab으로 이동하고 Ctrl+A/C/V 등 기본 입력 편집 키도 사용할 수 있습니다. 안내가 열린 동안에는 뒤의 입력 항목을 조작하지 않으며, 안내를 닫으면 이전 포커스를 복원합니다. 추가 통화는 통화 목록에서 선택하세요.

## 화면 테마

**추가 설정 → 화면 테마**에서 선택하면 재실행 없이 즉시 바뀌며, 입력 금액과 계산 결과를 유지합니다.

- **갸루 · 핑크 반짝임**: 기본 테마입니다. 핑크 그라데이션, 짙은 지브라 무늬 제목 표시줄, 하트와 골드 포인트를 사용합니다.
- **클래식 · 기존 디자인**: 기존의 밝은 회색 배경과 네이비·블루 디자인입니다.

마지막 테마 선택을 저장합니다. 기존 설정에 테마가 없거나 저장된 테마를 알 수 없으면 갸루 테마를 적용합니다. 두 테마 모두 한국어 화면, 고정 크기, 항상 위 표시를 유지합니다.

## 관세율 찾기

추가 설정의 **관세율 입력칸 옆 ? 버튼**을 누르면 현재 테마의 팝업이 열립니다. 다음 세 질문에 답하세요.

1. 물품 종류: 의류, 신발, 전자·생활용품, 식품·건강기능식품, 트레이딩 카드, 기타
2. 세부 품목: 소재·용도를 포함한 가장 가까운 품목
3. 관세율 적용 방식: 대표값으로 추정, 공식 확인한 적용 관세율 입력, 특별세 대상

면 편물 티셔츠·양모/면 니트·섬유 갑피 운동화는 대표 참고값 13%, 고무 방수 장화·일부 전열기구는 8%를 제안합니다. 유아복, 다른 전자제품, 식품 등 분류를 특정할 수 없는 품목에는 임의의 세율을 제안하지 않습니다. 공식 확인한 세율은 0~100%로 직접 입력할 수 있습니다. 발송지나 제조국만으로 FTA 관세율을 자동으로 0%로 바꾸지 않습니다. 주류·담배·고가품 등 특별세 대상은 적용을 막고 관세청 전체 세액 계산을 안내합니다.

포켓몬 등 오락용 트레이딩 카드는 관세율 도움말에서 선택할 수 있습니다. 오락용 카드(HSK 9504.40-0000) 분류 사례와 관세청 양허표의 기본세율 0%를 반영합니다. 가격이 자가사용 소액면세 기준 이내이면 관세·부가세가 면제되고, 기준을 초과하면 관세는 0%로 계산하되 부가세 10%는 계산합니다. 이는 카드의 성격과 통관 분류가 오락용 카드에 해당한다는 전제의 예상값이며, 수집용 인쇄물 등 다른 품목분류일 수 있는 물건은 관세청에서 확인하세요.

**관세율 적용**을 눌러야 입력칸에 반영됩니다. 알려진 품목은 물품 구분도 함께 조정하며, 식품·건강기능식품을 적용하면 목록통관 제외로 바꿔 미국 발송이어도 150달러 기준을 사용합니다. 취소·Esc·창 닫기는 기존 입력을 유지합니다. 면세 여부는 제안 관세율과 별도로 상품 가격·발송지·물품 구분에 따라 계산합니다.

대표값은 실시간 세율 조회나 확정 품목분류가 아닙니다. 의류·신발의 예시는 관세청에 게시된 과거 양허표의 기준세율을 참고하며, 현재 적용세율·FTA는 반드시 다시 확인해야 합니다. 팝업에서 품목별 근거를 열 수 있습니다. 2026-10-09에 확인한 근거:

- 의류 예시: [관세청 한·싱가포르 양허표 기준세율](https://www.customs.go.kr/download/ftaportalkor/_down/trty/han_sg_05.pdf)
- 신발 예시: [관세청 한·EU 양허표 기준세율](https://www.customs.go.kr/download/ftaportalkor/_down/trty/han_eu_1_05.pdf)
- 일부 전열기구: [CLIP HS 8516.79-9000, 2026년 기본세율 8%](https://unipass.customs.go.kr/clip/hsinfosrch/openULS0201007Q.do?opnMod=P&searchVal=8516799000)
- 오락용 카드: [관세청 한·이스라엘 양허표, HSK 9504400000 기본세율 0%](https://www.customs.go.kr/download/ftaportalkor/_down/trty/kor_is_04.pdf); [트레이딩 카드 품목분류 사례](https://www.kctdi.or.kr/kctdi/research/research03.do?articleNo=3996&attachNo=3618&mode=download)
- 현행 품목·전체 세액 확인: [관세청 해외직구 예상세액 계산기](https://www.customs.go.kr/kcs/ad/tax/BuyTaxCalculation.do)

## 계산 기준

자가사용 소액면세 요건을 충족하는 해외직구 물품을 기준으로 계산합니다.

| 발송지 | 물품 구분 | 상품 가격 면세 기준 |
| --- | --- | --- |
| 미국 | 목록통관 대상 | 미화 200달러 이하 |
| 미국 | 목록통관 제외 | 미화 150달러 이하 |
| 미국 외 | 목록통관 대상 | 미화 150달러 이하 |
| 미국 외 | 목록통관 제외 | 미화 150달러 이하 |

목록통관 제외 물품도 150달러 이하의 자가사용 물품이면 관세·부가세 소액면세가 적용됩니다. 기준을 초과하면 면세 한도를 공제하지 않고 **전체 과세가격**에 과세합니다. 별도로 구분한 국제 배송비·보험료는 면세 판단용 상품 가격에서는 제외하고, 과세 시에는 과세가격에 포함합니다.

- 과세가격 = 상품 가격 원화 환산액 + 국제 배송비·보험료 원화 환산액
- 관세 = 과세가격 × 입력한 관세율
- 부가세 = (과세가격 + 반올림 전 관세) × 10%
- 총액 = 상품 가격 + 국제 배송비·보험료 + 예상 관세 + 예상 부가세

**기본 관세율 8%는 추정용 가정이며 모든 품목의 세율이 아닙니다.** 두 물품 구분은 면세 기준을 결정하며, 정확한 세율은 품목분류·원산지·FTA 등에 따라 달라집니다. 관세청 품목별 계산기로 확인한 세율을 추가 설정에 입력하세요. 주류·담배·고가품 등의 별도 세금, 카드 수수료, 통관 수수료, 수량 제한과 합산과세는 이 계산에 포함하지 않습니다. 관세와 부가세는 각각 원 단위로 반올림하며 실제 세관 산정 규칙과 다를 수 있습니다.

2026-10-08에 [관세청 특송물품 통관 안내](https://www2.customs.go.kr/kcs/cm/cntnts/cntntsView.do?cntntsId=819&mi=2821) 및 [해외직구 예상세액 조회](https://www.customs.go.kr/kcs/ad/tax/BuyTaxCalculation.do)를 확인했습니다. 앱에서도 관세청 계산기로 이동할 수 있습니다. 환산에는 일일 시장 기준환율을 사용하므로 실제 관세청 주간 과세환율에 따른 세액과 차이가 있을 수 있습니다.

## 환율과 설정

HTTPS [Frankfurter v2 API](https://frankfurter.dev/)의 최신 일일 기준환율을 사용합니다. 실행·통화 변경·새로고침 및 실행 중 30분 간격으로 조회하며, 가격 변경은 저장된 환율로 즉시 계산합니다. API에는 통화 코드만 전송하고 입력 가격은 전송하지 않습니다. API 키나 외부 패키지는 필요하지 않습니다.

환율 기준일을 화면에 표시합니다. 휴일에는 이전 영업일 환율이 제공될 수 있으며 장중 실시간 환율은 아닙니다. 인터넷 오류 시 해당 통화의 저장된 환율을 날짜와 **오프라인 · 저장된 환율** 표시와 함께 사용합니다. 저장된 환율이 없으면 금액을 표시하지 않습니다. 저장된 환율에는 강제 만료 기간이 없으므로 기준일을 확인하세요.

통화·위치·테마 설정과 통화별 환율은 `%LOCALAPPDATA%\HowMuch`의 JSON 파일에 저장합니다. 파일이 없거나 손상되어도 실행되며, 해당 폴더를 삭제하면 초기화됩니다.

## WSL 2에서 빌드·실행

Windows .NET 8 SDK가 필요하며 WSL PATH에서 `dotnet.exe`를 찾을 수 있어야 합니다. Windows 드라이브에 있는 이 저장소에서 실행합니다.

```bash
dotnet.exe build howmuch.csproj -c Release
dotnet.exe run --project howmuch.csproj -c Release
```

앱은 WSL의 Windows 연동 기능을 통해 네이티브 Windows 창으로 실행됩니다. 일반 빌드 결과는 `bin/Release/net8.0-windows/howmuch.exe`이며 Windows .NET 8 Desktop Runtime이 필요합니다. 실행 파일과 동반 파일을 함께 유지하세요.

런타임을 포함하는 Windows x64 배포 폴더:

```bash
dotnet.exe publish howmuch.csproj -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

Windows 탐색기에서 `artifacts\win-x64\howmuch.exe`를 엽니다. 배포 시 **폴더 전체**를 복사하세요. ARM64 기기에서는 `win-arm64`와 별도의 출력 폴더를 사용합니다. 첫 배포 빌드는 런타임 팩을 다운로드할 수 있습니다.

## 검증

```bash
dotnet.exe run --project tests/HowMuch.Checks.csproj -c Release
dotnet.exe run --project tests/WidgetChecks/WidgetChecks.csproj -c Release
```

첫 테스트는 발송지·물품 구분별 면세 경계, 전체 금액 과세, 배송비, VAT, 통화 우선순위, 숫자 입력, 설정 저장, 잘못된 환율, 오프라인 및 취소 처리를 98개 검증합니다. 두 번째 테스트는 임시 설정과 가짜 환율을 사용해 네이티브 Windows WPF 창을 잠시 엽니다. 한국어 화면 배치, 기본 물품 선택, 지원 종료 통화 복구, 입력 즉시 계산, 미국 발송·제외 물품 전환, 추가 설정 순서, 관세율 팝업 질문·적용·취소·물품 구분 전환, 통화 저장, 추가 통화 환산, 단축키 명령·포커스·새로고침·안내·최소화·종료, 빠른 통화 변경, 기본 테마·실시간 전환·저장·복원을 검증합니다. 테스트는 실제 환율 API나 사용자의 설정을 사용하지 않습니다.

Windows에서 추가 수동 확인할 항목:

- 서로 다른 DPI의 모니터 간 드래그와 모니터 제거 후 재실행
- 일반 창 위의 항상 위 표시 및 키보드 탐색
- 최소화·복원, 종료·재실행 및 통화·위치 복원
- 인터넷 해제 시 저장 환율 표시, 미저장 통화 선택, 재연결 후 복구
- 100%·150%·200% 배율 및 접근성 설정에서 표시 확인

테마 렌더링을 PNG로 확인하려면 두 번째 명령 뒤에 `-- --capture-themes`를 추가합니다. 결과는 `artifacts/theme-previews/`에 저장됩니다.

`Shortcuts/`는 단축키와 안내, `Themes/`는 테마 리소스와 전환, `Core/`는 계산, `Services/`는 네트워크와 저장, `MainWindow.xaml`과 코드비하인드는 화면을 담당합니다. 개발 지침은 [AGENTS.md](AGENTS.md)에 있습니다.
